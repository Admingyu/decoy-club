# Decoy Club

Repository scaffold for the Decoy Club backend and frontend applications.

## Structure

- `backend/` Go API service scaffold
- `frontend/` Vue 3 + Vite application scaffold

## Notes

- Backend entrypoint: `backend/cmd/server/main.go`
- Frontend entrypoint: `frontend/src/main.ts`
- The repository currently only contains scaffold files for the initial setup task.
